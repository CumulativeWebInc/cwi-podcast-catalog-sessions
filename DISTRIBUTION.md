# Distribution — Post-Trap Futurism: The Catalog Sessions

**Stable feed URL (paste this everywhere):**
`https://cumulativewebinc.github.io/cwi-podcast-catalog-sessions/feed.xml`

**Why this exists:** the old muse.ai feed 302-redirected to expiring signed CDN URLs, so no directory
could index it. This feed points at permanent GitHub Pages URLs. Submit once per directory below.

**Indexing time:** directories take 24–72 hours to review and index after submission. The show will
NOT appear in Spotify search until Apple/Spotify finish indexing — that is normal, not a failure.

---

## Spotify — Spotify for Podcasters (Black taps this, ~2 min)

1. Open https://podcasters.spotify.com → log in with your Spotify account.
2. Click **Add a podcast** (or the `+`).
3. Paste the feed URL above when asked for the RSS feed → **Next**.
4. Verify ownership (Spotify shows a code to confirm — follow the on-screen step).
5. Review the show details → **Submit**.
6. Done. Episodes appear in Spotify search within 24–72h.

## Apple Podcasts — Apple Podcasts Connect (Black taps this, ~2 min)

1. Open https://podcastsconnect.apple.com → sign in with your Apple ID.
2. Click the **+** → **New Show** → **Add a show with an RSS feed**.
3. Paste the feed URL above → **Add**.
4. Review validation (all 25 episodes, cover art, "Music" category) → **Publish**.
5. Done. Apple lists the show in 24–72h; most other apps (Overcast, Pocket Casts) pull from Apple's directory automatically.

## Overcast (no action needed)

Overcast indexes via Apple's directory. Once Apple lists the show, it becomes searchable in Overcast.
If impatient: in Overcast, tap `+` → paste the feed URL directly.

## Pocket Casts (optional, ~1 min)

1. Open https://www.pocketcasts.com/submit/ → paste the feed URL.
2. Done — Pocket Casts also mirrors Apple's directory, so this is a belt-and-suspenders step.
